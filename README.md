# Athanasios Klidaras — personal website

Published at https://athanasiosklidaras.github.io/

Static HTML and CSS. No build step or dependencies are required.

## Updating

Edit the HTML pages and `style.css`, then commit to `main`. GitHub Pages publishes from the root of `main`.

The Resume page links to a PDF file in `assets/resume/`.
Project and infographic images retain their original resolution. Only the profile photo and award images use smaller web versions; original versions remain available where linked.

Images retain the credits given in their captions. No blanket license is granted for third-party images.
